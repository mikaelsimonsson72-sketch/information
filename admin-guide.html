📋 Översikt

Denna guide visar hur du som administratör uppdaterar informationen som visas för användarna. Systemet använder JSON-filer för att lagra data, vilket gör det enkelt att uppdatera innehållet.

💡 Tips: Alla ändringar träder i kraft direkt när filerna uppdateras på GitHub. Användarna ser ändringarna nästa gång de laddar om sidan.

🌐 Metod 1: Uppdatera via GitHub Web Interface (Enklast)

  1. Logga in på GitHub
    Gå till ditt repository på GitHub.com
  2. Navigera till datafilen
    Klicka på mappen data/ och välj den fil du vill uppdatera:
    • current-week.json - Innevarande veckas information
    • upcoming-weeks.json - Kommande veckors översikt
  3. Redigera filen
    Klicka på pennikonen (Edit) i övre högra hörnet
  4. Gör dina ändringar
    Uppdatera texten enligt instruktionerna nedan
  5. Spara ändringarna
    Scrolla ner, skriv en beskrivning av ändringen (t.ex. "Uppdaterad vecka 21")
    Klicka på "Commit changes"
  6. Vänta 30-60 sekunder
    GitHub Pages uppdaterar automatiskt sajten

💻 Metod 2: Uppdatera via VS Code (För tekniska användare)

  1. Öppna projektet i VS Code
    File → Open Folder → Välj projektmappen
  2. Hitta och öppna JSON-filen
    Navigera till data/current-week.json eller data/upcoming-weeks.json
  3. Redigera innehållet
    Gör dina ändringar direkt i editorn
  4. Spara filen
    Ctrl+S (Windows) eller Cmd+S (Mac)
  5. Commit och push till GitHub
    Använd VS Codes Git-integration eller terminalen:
    git add data/current-week.json
    git commit -m "Uppdaterad vecka 21"
    git push

📄 Filformat: current-week.json

Struktur

{ "weekNumber": 21, "year": 2026, "lastUpdated": "2026-05-25T15:30:00Z", "title": "Vecka 21 - Information", "content": "Huvudtext för veckan...", "sections": [ { "heading": "Måndag 25 maj", "text": "Information för måndag..." } ] }

Fältbeskrivningar

  • weekNumber: Veckonummer (1-52)
  • year: År (YYYY)
  • lastUpdated: Tidsstämpel i ISO 8601 format (använd aktuell tid)
  • title: Rubrik som visas överst
  • content: Huvudtext/introduktion för veckan
  • sections: Array med sektioner (dagar, kategorier, etc.)
💡 Tips för formatering:
  • Använd \n för radbrytningar
  • Använd • eller - för punktlistor
  • Länkar formateras automatiskt

📅 Filformat: upcoming-weeks.json

Struktur

{ "lastUpdated": "2026-05-25T15:30:00Z", "weeks": [ { "weekNumber": 22, "year": 2026, "summary": "Kort översikt för vecka 22..." } ] }

Fältbeskrivningar

  • lastUpdated: Tidsstämpel för senaste uppdatering
  • weeks: Array med kommande veckor (rekommenderat 4-6 veckor)
  • weekNumber: Veckonummer
  • year: År
  • summary: Kort sammanfattning (2-3 meningar)

✅ Vanliga uppgifter

Uppdatera innevarande vecka

  1. Öppna data/current-week.json
  2. Ändra weekNumber till aktuell vecka
  3. Uppdatera lastUpdated till aktuell tid
  4. Ändra innehållet i sections
  5. Spara och commit

Lägga till ny sektion

{ "heading": "Ny rubrik", "text": "Din text här..." }

Lägg till detta objekt i sections-arrayen, separera med komma.

Ta bort en sektion

Ta bort hela objektet från sections-arrayen. Glöm inte att ta bort kommat om det är sista elementet.

🔧 Felsökning

Sidan visar inte uppdateringar

  • Vänta 1-2 minuter efter commit
  • Ladda om sidan med Ctrl+F5 (tvinga refresh)
  • Kontrollera att GitHub Actions körde utan fel

JSON-fel

⚠️ Vanliga fel:
  • Glömt komma mellan element
  • Extra komma efter sista elementet
  • Citattecken som inte stängts
  • Felaktig escape-sekvens (använd \\ för backslash)

Validera JSON

Använd en JSON-validator innan du sparar:

  • JSONLint.com
  • VS Code har inbyggd JSON-validering

⭐ Bästa praxis

  • Uppdatera regelbundet: Håll informationen aktuell, helst varje måndag
  • Var koncis: Korta, tydliga meddelanden fungerar bäst på mobiler
  • Använd struktur: Dela upp information i sektioner för bättre läsbarhet
  • Testa på mobil: Kontrollera hur det ser ut på telefon efter uppdatering
  • Backup: Git-historiken är din backup, men spara viktiga versioner lokalt också
  • Commit-meddelanden: Skriv tydliga beskrivningar av vad du ändrat
💡 Pro-tips: Skapa en mall för varje vecka så du bara behöver fylla i ny information istället för att skriva om allt från början.

📞 Behöver du hjälp?

Om du stöter på problem eller har frågor:

  • Kontrollera GitHub Actions-loggen för felmeddelanden
  • Se över JSON-syntaxen med en validator
  • Återställ till tidigare version via Git-historiken
